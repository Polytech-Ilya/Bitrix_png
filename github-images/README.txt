КАРТИНКИ ДЛЯ GITHUB

13 изображений из текущего preview. Файлы сверены с картинками, встроенными в HTML. Логотип и баннер скопированы без изменения содержимого; имена переименованы латиницей.

Загрузите PNG/JPG из этой папки в выбранную папку публичного репозитория. Сам архив загружать вместо картинок не нужно.
Для письма нужны прямые HTTPS-адреса файлов, например:
https://raw.githubusercontent.com/OWNER/REPOSITORY/BRANCH/PATH/logo-politehnika.png
Ссылка github.com/.../blob/... ведет на страницу GitHub и не подходит как src изображения.
Репозиторий должен быть публичным, чтобы изображения открывались без авторизации. Не перемещайте и не удаляйте файлы после отправки рассылки.

После загрузки пришлите ссылку на репозиторий/папку и название ветки. Подставим прямые адреса в HTML.

Примечание: social-*.png содержат белые символы на прозрачном фоне. Серый круг и синяя подсветка задаются HTML/CSS; на белом фоне сами значки могут быть плохо видны.
